# Smart Budget – Web / PWA version
Upload ALL files in this folder to any HTTPS static host (Netlify Drop, GitHub Pages, Cloudflare Pages, Firebase Hosting).
Open the link in Chrome on Android → ⋮ → Install app. iPhone: Safari → Share → Add to Home Screen.
Edit in index.html: PAYMENT_URL, PRO_CODE, and paste ad code in the two marked ad slots. After changing files, bump the cache name in sw.js (sbem-v2 → sbem-v3).
Note: the Pro unlock is client-side only.
